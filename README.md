# Ứng dụng Quản lý Thu Chi

## Cách chạy

### 1. Khởi động Backend
```bash
cd backend
node server.js
# Chạy tại: http://localhost:3001
```

### 2. Khởi động Frontend (mở terminal mới)
```bash
cd frontend
npm run dev
# Mở trình duyệt: http://localhost:5173
```

## Tính năng
- Đăng ký / Đăng nhập bằng số điện thoại
- Nhập khoản Thu / Chi với nội dung và số tiền
- Xem lịch sử giao dịch
- Báo cáo tổng thu, tổng chi, số dư theo hôm nay / 7 ngày / tháng này
- Biểu đồ tròn tỷ lệ thu chi
- Biểu đồ cột theo ngày
